# PsiMole

[English](README.md) · [Демо](README.md#see-it-in-action) · [Поставить звезду](https://github.com/lilter96/PsiMole)

PsiMole — расширение GNOME Shell для Psiphon на Linux. Крот в каске живёт
в верхней панели, роет туннель при подключении и зажигает фонарь, когда
туннель открыт.

- Выбирай страну выхода и смотри время работы, задержку и скорость.
- Переключай системный прокси GNOME для приложений, которые его поддерживают.
- Смотри, какие программы используют туннель, и выключай его сразу или после
  закрытия этих программ.
- При желании закрепи отдельную страну для Claude с помощью защиты на Rust.

## Установка

Нужны Linux с GNOME Shell 46–51, Git и `curl` или `wget`. Установщик
скачивает консольный Psiphon для x86_64 и запускается без `sudo`. Если Psiphon
уже установлен в `~/psiphon`, установщик использует его и сохраняет настройки.

```sh
git clone https://github.com/lilter96/PsiMole.git
cd PsiMole
./install.sh --lang ru
```

На Wayland выйди из сеанса GNOME и войди снова. На X11 нажми Alt+F2,
введи `r` и нажми Enter. Щёлкни по кроту в верхней панели и включи туннель.
Чтобы использовать его в приложениях с системными настройками прокси,
включи **Системный прокси** в меню крота.

Из терминала работают `psi-on`, `psi-off`, `psi status` и
`psi region AT`. Последняя команда выбирает Австрию.
[Параметры установки и совместимость](README.md#quick-start)

## Защита Claude по стране

Дополнительная защита для Ubuntu охватывает Claude Code, Claude в настроенном
Firefox и известные адреса Anthropic. Выбери разрешённую страну в строке
**Claude**. В строке **Страна** выбери выход Psiphon. Когда соединение
оборвётся, защита закроет защищённые соединения. После переподключения она
снова проверит страну выхода перед тем, как пропускать запросы.

Защита настраивает правила сети и DNS для одной локальной учётной записи.
[Установка, требования и границы защиты](guard/README.md)
